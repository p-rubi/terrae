## How to cite

Cite the release you used:

```
Terrae: boundaries of countries, territories and their first- and second-level divisions, release 2026.10 [data set]. Data © OpenStreetMap contributors, Open Database License 1.0.
```

Each release has a fixed version and a manifest of checksums, so a citation identifies the exact data.
